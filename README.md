# Neon Runner — نئون‌گَرد

> A fast-paced neon space shooter that runs entirely in your browser.  
> Built with pure HTML5 Canvas and Web Audio API — no frameworks, no assets, no dependencies.

**Neon Runner** is a single-file arcade shooter with a Persian UI, glowing visuals, and fully synthesized sound effects. Just open the HTML file and play.

---

## ✨ Features

- 🎮 **Multiple control schemes** — mouse, touch, or keyboard (WASD / arrow keys)
- 🔫 **Auto-fire combat** with 4 weapon upgrade levels
- 👾 **4 enemy types** — grunts, zig-zaggers, tanks, and divers
- 👹 **Boss fights every 5 waves** with unique attack patterns and a dedicated health bar
- 🛡️ **Power-ups** — weapon upgrades, shields, and extra lives
- 🎨 **Neon visual style** — starfield background, particle effects, screen shake, and glow
- 🔊 **Synthesized audio** — all sound effects generated at runtime via Web Audio API
- 📱 **Fully responsive** — works on desktop, tablet, and mobile
- 🏆 **Local high score** saved in your browser
- 🧩 **Zero dependencies** — everything in one HTML file

---

## 🕹️ How to Play

1. Download or clone this repository.
2. Open `index.html` in any modern browser.
3. Move with your mouse, finger, or WASD / arrow keys.
4. Shooting is automatic — focus on dodging and aiming.
5. Survive as long as you can and beat your high score!

**Pause / Resume:** `Esc` or `P`

---

## 🛠️ Technical Details

- **Rendering:** HTML5 Canvas 2D
- **Audio:** Web Audio API (oscillators + noise buffers)
- **State management:** Plain JavaScript with a simple game loop
- **Storage:** `localStorage` for high score persistence
- **No build step, no external libraries, no image or sound files**
